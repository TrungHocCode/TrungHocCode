## 🔭 What am I currently working on?

### [AgentFlow](https://github.com/TrungHocCode/agentflow)

**A local-first multi-agent workbench for technology research.**

AgentFlow turns a research request into a workflow that can be **reviewed, approved, executed, and inspected**. It combines conversational planning, deterministic workflow execution, role-specific agents, tool use, local LLM inference, and structured evaluation.

Through this project, I'm currently exploring:
